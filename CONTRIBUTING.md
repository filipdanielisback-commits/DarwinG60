# Contributing to DarwinG60

Thanks for your interest in the project. The most useful early contributions are careful research, documentation, source references, and small reproducible experiments.

## Before opening a change

1. Read the project scope in [README.md](README.md).
2. Check the [roadmap](ROADMAP.md) to avoid duplicating work.
3. For technical claims, include a link to a primary source where possible.
4. Mark uncertain statements as **unverified** rather than presenting them as facts.
5. Do not commit proprietary firmware, copyrighted Apple components, personal data, passwords, tokens, or device identifiers.

## Good contributions

- Correcting or expanding hardware documentation with sources.
- Explaining a relevant ARM64, EFI, or XNU concept.
- Adding reproducible research notes or non-destructive tests.
- Improving build documentation after a procedure has actually been tested.
- Reporting errors with enough context to reproduce them safely.

## Pull request checklist

- [ ] The change has a clear purpose.
- [ ] Technical claims include sources or are labelled as hypotheses.
- [ ] No proprietary or confidential material is included.
- [ ] Documentation does not claim untested functionality.
- [ ] Any code includes a short explanation of how it was tested.

Please keep changes focused and respectful. There is no expectation that contributors test experimental software on their personal phones.
